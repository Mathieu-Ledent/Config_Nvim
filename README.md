# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

# Install : 
First you need to have neovim install on your computer. You can find how get neovim from this link [neovim](https://neovim.io/).
Then if you had a neovim config already installed. Make a backup with this command :
`mv ~/.config/nvim/ ~/.config/nvim_backup/` 
and **clone** the repo
